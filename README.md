# Customer Segmentation Analysis

## Project Overview
This project groups mall customers into 5 distinct categories based on their **Annual Income** and **Spending Score** to help businesses create targeted marketing plans. This project was successfully developed as part of the **Thiranex** Customer Segmentation training task.

## Tools Used
* **Python (VS Code):** Built the K-Means Clustering model to group the data efficiently using Scikit-Learn.
* **Power BI:** Created an interactive dashboard mapping clusters into real business personas (Target Segment, Careful Spenders, etc.) to deliver targeted insights.
